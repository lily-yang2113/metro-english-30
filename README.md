# 地铁英语30分钟

面向地铁通勤场景的纯前端英语主动输出训练应用。移动端优先，不需要麦克风、语音识别或录音。

## 运行

在项目目录执行：

```powershell
python -m http.server 4173
```

然后打开 `http://127.0.0.1:4173/`。浏览器数据保存在 `localStorage`，首次打开后核心页面可离线访问。

项目是纯静态应用，可直接托管在 GitHub Pages 的仓库根目录。

## 已实现

- 30 分钟四阶段流程：抽卡热身、精学课文、输出训练、收尾做卡
- 课程队列连续推进：每课 Day 1 / Day 2，完成后自动进入下一课 Day 1
- 阶段倒计时、暂停、重置与手动切换
- Day 1 / Day 2 独立进度
- 到期卡片抽取、答案揭示、连续成功计数和间隔复习
- 连续 3 次成功标记掌握，失败后安排到明天
- 课文原文、折叠翻译、核心句型和自定义句型笔记
- 整篇课文连续朗读：自动选择设备 Natural/Neural 美式语音，支持声线、语速、暂停和停止；配置 API 后可切换 AI 美音
- 逐句中文回译、本地逐词差异高亮、匹配度评分
- 50 词以上开放写作：不限定主题，可选标题、本地五维评分、改进建议、AI 深度点评和写作历史
- 低分回译自动进入错题本，可标记解决或删除
- 薄弱句一键做卡，以及手动新建、编辑、删除卡片
- 学习概览：待复习卡片、连续学习、掌握句型、已学课文
- 学习数据导出、导入与恢复初始数据
- PWA 离线缓存入口

## API 配置

打开“设置”，填写：

- `Base URL`：OpenAI 兼容接口，例如 `https://api.openai.com/v1`
- `模型名称`：例如 `gpt-4o-mini`
- `语音模型`：例如 `gpt-4o-mini-tts`
- `美音声线`：可选 Alloy、Nova、Coral、Sage、Ash、Onyx
- `API Key`：只保存在当前浏览器

启用后，在回译页点击“AI 批改”，或在写作页点击“AI 深度点评”，应用会请求：

```text
POST {Base URL}/chat/completions
```

接口需允许浏览器跨域访问。纯前端应用无法隐藏 API Key，请使用权限受限的测试密钥，不要在公共设备上保存。课文整篇朗读使用浏览器内置英语语音，不依赖 API，也不会使用麦克风。

## 课程内容说明

当前课程队列包含 `A Puma at Large`、`The Lost Notebook` 和 `The Night Train` 三篇原创仿写样课，只用于演示完整训练流程，未复制《新概念英语》课文正文。若要用于正式学习，请在 `app.js` 的 `COURSE_LESSONS` 数组中替换或追加已获得使用许可的课文、翻译、句型与逐句数据。

## 文件

- `index.html`：页面入口
- `styles.css`：移动端视觉与响应式布局
- `app.js`：状态、训练流程、卡片算法、差异对比和 API 调用
- `manifest.webmanifest`、`sw.js`、`icon.svg`：PWA 与离线支持
